# Descripción del proyecto

Aplicación web desarrollada con HTML, CSS, JavaScript y Bootstrap
que permite visualizar una imagen SVG y modificar sus dimensiones
mediante cinco botones.

El proyecto utiliza Git para administrar el control de versiones
local y GitHub para almacenar y publicar el repositorio remoto.

## Objetivo

Crear una aplicación web que permita sustituir una imagen JPG
por una imagen SVG, implementar controles para modificar sus
dimensiones y administrar los cambios mediante Git y GitHub.

## Funcionalidades

La aplicación cuenta con cinco botones que permiten modificar
el tamaño de la imagen SVG.

| Botón | Ancho |
|---|---:|
| X-Pequeño | 100 px |
| Pequeño | 200 px |
| Mediano | 300 px |
| Grande | 400 px |
| X-Grande | 500 px |

La altura de la imagen se ajusta automáticamente para conservar
sus proporciones originales.
